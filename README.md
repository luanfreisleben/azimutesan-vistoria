# AzimuteSAN — Vistoria de Ativos

PWA local-first para cadastro e vistoria de ativos de saneamento (SAA, SES, RSU, Drenagem) em campo, com funcionamento offline.

- Stack: React + TypeScript + Vite + vite-plugin-pwa + Dexie (IndexedDB)
- Hospedagem: GitHub Pages
- Uso principal: iPhone/Android instalado na tela inicial

## Status

- [ ] Fase 1 — estrutura, PWA, IndexedDB, projetos, ativos, vistoria, auto-save, offline
- [ ] Fase 2 — fotos, GPS, checklists, avaliações, registros recentes
- [ ] Fase 3 — CSV, JSON, ZIP, importação, backup
